💾 บันทึกโครงการทั้งหมด

ส่งออกข้อมูลทั้งหมดทุกเมนู เป็นไฟล์ JSON ฉบับเดียว เพื่อสำรองข้อมูลหรือนำไปใช้ต่อ — ในไฟล์มี:

    📂 นำเข้า / เริ่มโครงการใหม่

    นำเข้าไฟล์ที่บันทึกไว้: JSON (บันทึกทั้งหมด / โครงการ) · XLSX ที่ส่งออกจากโปรแกรม (หรือที่ลูกค้าแก้กลับมา) · CSV รายการงาน

    📁 โฟลเดอร์เก็บงาน

    ทุกปุ่ม บันทึก/ส่งออก (PDF · JSON · CSV · XLSX) บันทึกลงโฟลเดอร์ชื่อโครงการ ภายในโฟลเดอร์หลักที่เลือกไว้ (ไดรฟ์ไหนก็ได้)

    หลังเลือกโฟลเดอร์ เบราว์เซอร์จะถาม "Allow this site to edit files?" ต้องกด Allow — ถ้ากด Don't Allow จะบันทึกไม่ได้ (โปรแกรมจะแจ้งเตือนและให้เลือกใหม่)
